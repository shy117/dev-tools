# dev-tools

个人开发过程中使用的小型工具和脚本集合。

该仓库主要用于保存一些独立、轻量、可复用的开发辅助工具。不同工具按目录分别管理，每个工具目录中包含对应的说明文档、源码及必要的测试文件。

## 工具列表

### cdg-export

Windows 下的 CDG 项目导出工具。

在当前环境已授权 `cmd.exe` 且 `type` 命令能够读取源码明文的前提下：

- `.h`、`.cpp` 文件通过 CMD 读取并导出；
- 其他项目文件原样复制；
- 保留原有目录结构；
- 不修改源项目；
- 不覆盖已有输出目录；
- 对导出结果执行大小和 SHA-256 校验；
- 拒绝符号链接、目录联接等重解析点。

详细说明见：

```
cdg-export/README.md
```

## 目录结构

```
dev-tools/
├── README.md
└── cdg-export/
    ├── README.md
    └── export_project.py
```

后续其他独立开发工具也会继续按子目录加入该仓库。

## 说明

各工具之间相互独立，具体运行环境、使用方法和限制请查看对应目录中的 `README.md`。
