# CDG 项目导出工具

在已授权的 Windows 环境中，通过 CMD 导出 CDG 保护的 `.h`、`.cpp` 源文件，并复制项目中的其他文件，生成保留目录结构的项目副本。

不同环境的结果取决于 CMD 的明文读取权限及目标目录的 CDG 策略。

## 功能

- 支持导出整个项目目录或单个文件。
- `.h`、`.cpp` 文件通过 CMD 的 `type` 命令读取，扩展名匹配不区分大小写。
- 以二进制方式写入输出，不解码、不主动转换编码或换行。
- 其他文件原样复制，保留子目录结构和空目录。
- 对每个输出文件执行大小和 SHA-256 校验。
- 不修改源文件，不覆盖或合并已有输出目录，不显示源码内容或校验哈希。

## 运行环境

- Windows。
- Python 3.10 或以上版本，无需安装第三方依赖。
- 当前 CDG 环境已授权 `cmd.exe`，并已确认其 `type` 命令能够读取受保护源文件的明文。

脚本使用已有的 CMD 读取权限，不解除或修改 CDG 策略。

## 快速使用

将 `export_project.py` 保存到本地，在脚本所在目录打开 PowerShell 或 CMD。

### 导出整个项目

```powershell
python export_project.py "C:\Projects\MyProject" "C:\Exports\MyProject_plain"
```

项目内容直接放入输出目录，保留原有子目录结构，不额外嵌套项目文件夹。

### 导出单个文件

```powershell
python export_project.py "C:\Projects\MyProject\main.cpp" "C:\Exports\single_plain"
```

输出文件为 `C:\Exports\single_plain\main.cpp`。

### 参数

```text
python export_project.py <输入路径> <输出目录>
```

| 参数 | 说明 |
| --- | --- |
| 输入路径 | 已存在的普通文件或项目目录 |
| 输出目录 | 尚不存在的新文件夹；单文件模式下也必须指定文件夹 |

路径包含空格时，应使用双引号包裹。输出目录不能位于输入目录内部。

## 复制范围

| 文件类型 | 处理方式 |
| --- | --- |
| `.h`、`.cpp` | 由 CMD 打开源文件，Python 接收二进制输出并写入目标文件 |
| 其他文件 | 通过 Python 按字节复制，不执行 CMD 明文导出 |

目录模式会包含隐藏文件、`.git` 目录、构建产物和二进制文件，没有排除规则。其他扩展名的文件即使受到 CDG 保护，也不会自动按源码方式导出。

脚本通过 `copystat` 尽可能保留时间戳等基本属性，但这是项目文件内容复制，不是完整的文件系统备份，不承诺保留 NTFS ACL、备用数据流、硬链接关系或全部 Windows 文件属性。

## 扩展支持的后缀

默认通过 CMD 导出的后缀为 `.h` 和 `.cpp`。如果需要导出其他后缀的加密文本文件，在 `export_project.py` 的 `PROTECTED_SUFFIXES` 集合中添加对应后缀即可，例如：

```python
PROTECTED_SUFFIXES = {".h", ".cpp", ".c", ".hpp", ".txt"}
```

- 后缀必须包含开头的 `.`，并统一使用小写；脚本匹配时不区分大小写。
- 新增类型必须已确认能通过已授权 CMD 的 `type` 命令读取明文。
- 集合内所有匹配文件都会通过 CMD 导出，无论文件实际是否加密；集合外文件仍按原样复制。
- 导出时按字节写入，不主动转换文本编码或换行。

上文的 `.h`、`.cpp` 说明对应默认配置；修改集合后，CMD 导出范围以 `PROTECTED_SUFFIXES` 为准。

## 校验与限制

源码校验比较 CMD 导出的字节与通过 Python 普通读取目标文件得到的字节；其他文件校验比较复制时读取的字节与目标文件字节。每个文件均检查大小和 SHA-256。

字节一致说明写入和读取结果一致，但不能独立证明 CMD 输出一定是明文，也不能判断任意 CDG 格式或磁盘底层加密状态。使用前应确认 CMD 能正确读取明文，并了解目标目录的 CDG 策略对输出文件的影响。

输入、输出路径及其上级路径不能包含符号链接、目录联接或其他重解析点。项目内发现这些对象时，预检会失败，不开始复制。

导出期间应停止编辑源文件，保持项目内容稳定。脚本不会执行项目内代码、构建项目或执行 Git 操作。

## 执行结果

成功时，终端显示文件总数、CMD 导出数量、原样复制数量、输出字节数和校验结果。

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 导出失败 |
| `130` | 用户中断 |

运行过程中失败或中断时，输出目录可能保留不完整结果。重试必须指定新的输出目录，脚本不会覆盖或继续写入已有目录。

## 常见问题

### 输出目录已经存在

选择一个尚不存在的目录。该限制用于避免覆盖现有文件，不能通过重复运行来续传。

### CMD 读取失败

确认当前环境已授权 CMD，并且 `type` 命令能读取对应文件的明文。脚本不会调整 CDG 权限或策略。

### 校验通过，但内容仍不是明文

校验只确认字节一致。请检查 CMD 的实际读取结果和目标目录的 CDG 策略。
